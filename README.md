# ChessGameWithEngine
Chess terminal game with enemy engine written in c++. Engine uses AlphaBeta-Prunning (Min-Max algo with optimizations), MVV-LVA, Killer Moves, Quiescence, Iterative Deepening with Transposition Table (ZobristHash), Opening book (Sqlite Db-Conection) etc. Complex heuristics based eval function with concepts such as pawn islands and piece placement.
